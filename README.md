# Вебзастосунок пошуку коворкінгів (CoWorkUA)

Платформа для агрегації, пошуку та бронювання гнучких робочих просторів в Україні.[cite: 2] Проєкт створено з метою спрощення взаємодії між клієнтами, власниками коворкінг-просторів та адміністраторами платформи.[cite: 1, 2]

* **Frontend (Клієнтська частина):** [Посилання на Vercel](#)
* **Backend (API):** [Посилання на Render](#)
* **База даних:** MySQL розгорнуто на Clever Cloud.

## 🛠 Стек технологій[cite: 1, 2]

### Frontend[cite: 1]
* Побудовано на React 18 та TypeScript.[cite: 2]
* Збірка проєкту та HMR за допомогою Vite.[cite: 2]
* Utility-first стилізація через Tailwind CSS 4.[cite: 2]
* Управління глобальним станом застосунку реалізовано через Zustand.[cite: 2]
* HTTP-клієнт для взаємодії з API — Axios.[cite: 2]
* Інтерактивна карта реалізована за допомогою React Leaflet та даних OpenStreetMap.[cite: 2]
* Графіки та статистика відображаються через Recharts.[cite: 2]

### Backend[cite: 1]
* Реалізовано на C# та ASP.NET Core 9 Web API.[cite: 2]
* Взаємодія з БД через ORM Entity Framework Core 9.[cite: 2]
* Реляційна база даних: MySQL Server 8.0.[cite: 2]
* Безпека: JWT-автентифікація, BCrypt-хешування паролів та AES-256 шифрування персональних даних.[cite: 2]

## ✨ Основні функціональні можливості[cite: 1, 2]

* **Для клієнтів:** Доступний пошук коворкінгів за містом або на інтерактивній карті.[cite: 1, 2] Передбачено перевірку конфліктів бронювань у реальному часі.[cite: 2] Реалізовано безпечне бронювання робочого місця, генерацію QR-кодів, а також систему прозорих відгуків.[cite: 1, 2]
* **Для власників просторів:** Створення організації та додавання коворкінгів.[cite: 1, 2] Доступна панель управління підтвердженням та скасуванням бронювань.[cite: 1, 2] Для Premium-акаунтів реалізовано графічну аналітику доходів і завантаженості.[cite: 1, 2]
* **Для адміністраторів:** Платформа містить модуль модерації нових просторів.[cite: 1, 2] Адміністратор має інструменти управління користувачами та доступ до журналу аудиту (AuditLog) для відстеження всіх критичних операцій.[cite: 1, 2]

## 🏗 Архітектура[cite: 1]

Проєкт побудовано за класичною трирівневою клієнт-серверною архітектурою з чітким розмежуванням доступу на основі рольової моделі (Гість, Клієнт, Власник, Адміністратор).[cite: 1, 2] Серверна частина імплементує патерн `Controller - Service - DbContext` для слабкої зв'язності компонентів.[cite: 2]

## ⚙️ Локальний запуск

### Попередні вимоги
* Node.js (v18+)
* .NET 9 SDK
* MySQL Server 8.0

### Запуск серверної частини (Backend)
1. Перейдіть у папку бекенду.
2. Відредагуйте файл `appsettings.json`, вказавши ваші дані для підключення до локальної або хмарної MySQL (Clever Cloud).
3. Застосуйте міграції: `dotnet ef database update`
4. Запустіть сервер: `dotnet run`

### Запуск клієнтської частини (Frontend)
1. Перейдіть у папку фронтенду.
2. Встановіть залежності: `npm install`
3. Створіть файл `.env` та вкажіть базовий URL вашого API (наприклад, `VITE_API_URL=http://localhost:5000/api`).
4. Запустіть сервер розробки: `npm run dev`
