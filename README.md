# CoWorkUA — Вебзастосунок пошуку та бронювання коворкінгів[cite: 1, 2]

Цей проєкт є розробкою єдиної інформаційної платформи для зручного пошуку, порівняння та бронювання гнучких робочих просторів в Україні[cite: 2]. Проєкт створено в рамках кваліфікаційної бакалаврської роботи[cite: 1, 2].

## 🚀 Live Demo
* **Клієнтська частина (Frontend):** [Посилання на Vercel](https://твоє-посилання.vercel.app)
* **Серверна частина (Backend API):** [Посилання на Render](https://твоє-посилання.onrender.com/swagger)
* **База даних:** Розгорнута на Clever Cloud

## ⚙️ Стек технологій[cite: 1, 2]

**Frontend:**
* React 18 та TypeScript[cite: 1, 2]
* Збірка за допомогою Vite[cite: 2]
* Tailwind CSS 4 для utility-first стилізації[cite: 1, 2]
* Zustand для управління глобальним станом[cite: 2]
* React Leaflet та OpenStreetMap для інтерактивної карти[cite: 1, 2]
* Recharts для візуалізації графіків статистики[cite: 1, 2]

**Backend:**
* C# та ASP.NET Core 9 Web API[cite: 1, 2]
* Entity Framework Core 9 (ORM)[cite: 1, 2]
* JWT Bearer для безпечної автентифікації та рольової моделі[cite: 2]
* BCrypt для хешування паролів[cite: 2]

**Database:**
* MySQL Server 8.0[cite: 1, 2]

## 🎯 Основний функціонал[cite: 1, 2]

Проєкт реалізує комплексну взаємодію між орендодавцями та клієнтами з чітким розмежуванням ролей[cite: 2]:

* **Гість (неавторизований користувач):**
  * Перегляд публічного каталогу просторів з можливістю пошуку та застосування фільтрів[cite: 1, 2].
  * Візуальний пошук локацій на інтерактивній карті міста[cite: 1, 2].
  * Перегляд рейтингів та читання верифікованих відгуків[cite: 1, 2].

* **Клієнт:**
  * Бронювання робочих місць на конкретну дату та час[cite: 1, 2].
  * Автоматична перевірка конфліктів бронювань та наявності вільних місць у реальному часі[cite: 2].
  * Генерація QR-коду для підтвердження успішного бронювання на локації[cite: 1, 2].
  * Управління списком збережених коворкінгів (Улюблені) та залишення відгуків після відвідування[cite: 1, 2].

* **Власник коворкінгу:**
  * Зручний особистий кабінет для створення та редагування організації і коворкінгів[cite: 1, 2].
  * Управління вхідними запитами на бронювання від клієнтів (підтвердження / скасування)[cite: 1, 2].
  * Доступ до аналітики: графіки доходів, популярні години та завантаженість по днях тижня[cite: 1, 2].

* **Адміністратор:**
  * Панель управління для модерації (затвердження або відхилення) нових коворкінгів[cite: 1, 2].
  * Перегляд та управління всіма бронюваннями на платформі[cite: 1, 2].
  * Доступ до журналу аудиту (Audit Log) для відстеження критичних дій у системі[cite: 1, 2].

## 🏗 Архітектура та Безпека[cite: 2]
Проєкт побудовано за класичною трирівневою клієнт-серверною архітектурою[cite: 1, 2]. Серверний шар реалізовано з використанням шаблону «Controller – Service – DbContext», що забезпечує слабку зв'язність компонентів[cite: 2]. Усі персональні дані користувачів додатково шифруються за алгоритмом AES-256 безпосередньо перед записом до бази даних[cite: 2].
